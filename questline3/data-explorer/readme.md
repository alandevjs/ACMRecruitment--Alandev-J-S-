Students Performance Data Explorer Overview

This project performs an initial exploration of the Students Performance Dataset using Python and Pandas.

Dataset The dataset contains information about 1000 students and has 8 columns:

Gender Race/ethnicity Parental level of education Lunch Test preparation course Math score Reading score Writing score

Observations The dataset contains 1000 rows and 8 columns. The categorical columns are stored as object data types. The score columns are stored as int64 data types. There are no missing values in the dataset. The numerical features are math, reading, and writing scores.

The average scores are approximately: Math: 66.09 Reading: 69.17 Writing: 68.05

Reading has the highest average score among the three subjects. The scores range from 0 to 100, although the minimum values differ between the subjects
